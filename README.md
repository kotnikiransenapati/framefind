# FrameFind

FrameFind is a visual discovery app designed to help users search for images by topic and explore visual inspiration. This Part 1 submission builds the responsive search interface; image fetching will be added in Part 2.

I chose a forest-teal and warm-cream colour palette to create a calm, editorial feel that differs from typical image-search interfaces. I added quick-pick category chips to suggest search ideas and an illustrated empty state to make the page feel welcoming before results appear. The responsive CSS Grid is designed to accommodate image cards across phones, tablets, and desktop screens.
